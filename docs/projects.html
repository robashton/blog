Projects

Most of what I've built since 2015 belongs to id3as/Norsk rather than to me, and a lot of it isn't public. These are the bits that are.

At work

Norsk Studio

Originally created in a weekend with the goal of "Windows Forms for media workflows". It's a drag and drop builder for live media workflows on top of the Norsk SDK, where every component is loaded dynamically and comes with its own schemas, HTTP control surface, UI and metrics, so a workflow ends up with an API and a set of dashboards specific to the components it actually uses. It has come on a long way since that weekend and is now what the rest of the Norsk product range is built on (Playout, Remote Commentary and so on).

There's a video of me showing it to Jan Ozer if you want to see it in motion.

Pinto and Stetson

Opinionated Purescript bindings to OTP and Cowboy, from when we started writing our Erlang control plane code in Purerl instead. Open source, worked on by quite a few of us at id3as since. I wrote about them at length in a few series, and there's the Purerl Cookbook, which nobody reads.

Older things

I wrote a lot of code in my spare time, for learning, for pleasure and for competition, and I think a lot of whatever success I've had came from that.

  • CravenDB: I decided to learn Clojure and a project in a familiar domain would help, so I wrote a document database in it.
  • RavenDB: I used to contribute a lot to RavenDB, a document database written in C# (my fork).
  • HoverBattles: a multiplayer 3D battle game in JS and WebGL in the browser, back when that was unusual.
  • Swallow: a tool for packaging up game assets into a single file.
  • Github Live: a weekend hack streaming every event from Github into a live bar chart by language, in node.js.
  • SLJS: an experiment written during a conference to convert a Silverlight app into JS/HTML.
  • RavenGallery: an (outdated) and at one point popular example of an ASP.NET MVC application on RavenDB.
  • Ludum Dare games, each written in a weekend: 10 Second Bullet Hell (LD27), Centipede 2013 (LD25, reverse Centipede in ImpactJS), Tiny Protector (LD23) and You Don't Have To Be Alone (LD22, a platformer with a hidden cat).
