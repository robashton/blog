I used to speak at conferences quite a lot before the start-up life took me. Some of the talks were filmed, and these are the ones I can still find.

  • Norsk Studio: a developer's deep dive

    With Jan Ozer, 2024

    Showing Jan how Norsk Studio works under the hood.

  • Purescript on the BEAM: Typed OTP for greatness

    Code Mesh LDN, 2019

    What we'd been doing at work that year: writing OTP applications in Purescript, with a focus on the implementation details and nitty gritty. There's a post to go with it and some answers to questions afterwards.

  • Learning and the state of the web

    Øredev keynote, 2014

    I was asked to keynote a conference in Sweden, so I talked about stuff that was personal to me: learning, how our industry is a bit backwards, and how lowering the barrier isn't always the right thing to do.

  • React and NPM for great good

    DevDay

    A return to DevDay, this time talking about React. A lot of fun for the people in the room, though the interaction is somewhat lost in the video.

  • The software journeyman's guide to being jobless and homeless

    DevDay, 2013

    I spent 2013 as a wandering developer, working for free and for a roof over my head, because I was bored of the status quo and wanted to see what else I could learn out there. DevDay in Poland was one of my favourite conferences.

  • JavaScript sucks and it doesn't matter

    DevDay, 2012

    Frustrated with JavaScript, I talked about that frustration and how getting over it will help us become adequate JS developers.

  • Building and testing full-stack node apps

    Leetspeak, 2012

    Putting a bunch of modules together into a basic application in node.js.

  • WebGL - What?

    NDC, 2012

    Some fun with WebGL, and some points about framework usage.

  • Building awesome games with WebGL and Node.js

    altdotnet Italy, 2012

    Effectively the lessons I learned building HoverBattles.

  • Introduction to RavenDB

    NDC, 2011

    I gave quite a few talks on RavenDB and this basic introduction was one of the most popular.

  • Document databases with ASP.NET MVC

    NDC, 2011

    A bit outdated now and I'd give different advice these days, but there are some good hints in there about data modelling and view models.

  • Building pluggable web applications with ASP.NET MVC

    Øredev, 2010

    Just before ASP.NET MVC3 was released. Some valid advice, but again I'd take a different approach these days.

  • Model-first development in NHibernate using Fluent mappings

    NHDay, 2010

    A blast from the past, using NHibernate, something I'd not advocate these days. Still, I gave it and it's part of my history.

  • Multi-tenant apps in ASP.NET MVC

    DDD9

    ASP.NET MVC1, showing its age a bit. The kind of thing the small company I was working with at the time did to support lots of bespoke customers from a single codebase.
